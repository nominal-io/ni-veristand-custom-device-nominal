# ni-veristand-custom-device-nominal

Everything a person reads in this repo follows the Nominal docs hub's writing rules:

@../pub-docs/CLAUDE.md

If that import comes up empty, pub-docs isn't checked out beside this repo. Read
https://github.com/nominal-io/pub-docs/blob/main/CLAUDE.md instead. Its "Building and checking"
and "Repo conventions" sections are about pub-docs itself and don't apply here.

The rules cover more than the docs in `docs/`:
- the README
- the custom device's labels, help text and messages, in the VIs under `source/`
- the custom device's definition, `source/Custom Device Nominal Core Streaming.xml`

The product is Nominal. Every "Nominal Core" in this repo is wrong: in the README, in the
device's names, help text and messages, and in the repo's old name,
`ni-veristand-custom-device-nominal-core`. The repo is now
https://github.com/nominal-io/ni-veristand-custom-device-nominal.

The user docs quote the device's labels word for word, so changing one is a docs change too.
`docs/CLAUDE.md` has the rules for the pages themselves.
